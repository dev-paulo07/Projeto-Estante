# **Estante - Gerenciador de Leitura**

---

## **Desenvolvedor**
* Paulo Castro

---

> Este projeto se trata de uma página web que foi desenvolvida para a AV1 do Oxetech no curso de Dev Web Full Stack, tendo como objetivo principal de funcionalidade ser uma estante que possui gerenciador de leitura para organizar leituras de uma forma organizada e planejada. Possui um estilo minimalista e elegante para uma utilização confortável e dinâmica.

---

## **Tecnologias Utilizadas**
* **HTML5**
* **CSS3** (Customizado e Responsivo)
* **Bootstrap 5** (Layout e Componentes)
* **Font Awesome** (Ícones)
* **JavaScript Vanilla** (Manipulação dinâmica do DOM)
